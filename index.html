古代中国では、罪人に対する刑罰として「鼻削ぎ」が行われていたといいます。この刑罰は古い文献に繰り返し登場しますが、実際に刑を受けたことを示す人骨は、これまで確認されていませんでした。

中国の考古学者チームは、2018年に河南省三門峡市の三支園墓地を調査しました。この墓地では多くの人骨が発掘されましたが、その中に他の人骨とは異なる特徴を持つ女性の遺骨があったのです。

女性が埋葬された墓の年代は元王朝から明王朝初期にかけての1298～1404年で、亡くなった年齢は40～44歳と推定されています。埋葬では遺体を仰向けに安置するのが一般的ですが、彼女はうつ伏せに埋葬されていました。

これだけでも異様な雰囲気を感じますが、彼女の顔面（頭蓋骨の前面部）には、鼻の周辺に損傷痕と治癒痕が残っていたのです。これは生前に彼女が鼻に大きな傷を負い、その後、傷が治るまで生きていたことを意味します。

「鼻削ぎ刑」は、古代中国で用いられた「五刑」の一つで……窃盗などに対して科された記録があり、元代末期には家畜を盗んだ者への刑罰として用いられたことも記されています。

彼女の墓には青銅製の簪（かんざし）1本が副葬され、先述したように遺体はうつ伏せの状態で埋葬されていました。この簪が生前の愛用品だったのか、あるいは死後に近親者などが手向けたものだったのかは、明らかになっていません。

また、調査された同墓地の歴史時代の埋葬213例のうち、うつ伏せで埋葬されていたのは彼女だけだったのです。……ただし墓には彼女の身元や罪状を伝える文字記録が残されておらず、詳しい経緯は不明です。

戦前に神戸市内の鉄道工事現場の崩落事故などで亡くなった朝鮮人労働者13人の追悼式典が18日、同市兵庫区の慰霊碑前で開かれた。碑は、被害実態を調査した市民団体が1996年に設置してから今年11月で30年となる。団体の徐根植代表（75）は「過去の歴史の真実を忘れずに伝えていく」とあいさつした。

式典には市民ら約30人が参加。つるはしを振る男性の銅像に花を手向け、黙とうをささげた。

事故が起きたのは神戸電鉄（旧神戸有馬電気鉄道、三木電気鉄道）の敷設工事。団体によると、市中心部から山間部の有馬を結ぶ有馬線を中心に、多数の朝鮮人が雇用された。団体は当時の新聞記事を調べるなどし、27〜36年に死亡した13人を特定した。

（朝鮮新報より）神戸市の北および北西郊に路線をもつ現・神戸電鉄は、神戸有馬電鉄と三木電鉄が1947年に合併。1920年代から30年代に展開された敷設工事には、朝鮮人労働者1200～1800人が従事していたという。

原文抜粋（「……」は中略）

Claude Code から外部サービスを操作するときは、MCP のコネクタを使います。……自動化を進めていくと、コネクタも API も無いサービスがどうしても残ります。業務に合わせて選んだ小さな SaaS や、社内向けの管理コンソールです。

Claude Code に Chrome 拡張をつなぐと、ここに入口ができます。画面をそのまま読ませて、クリックや入力を任せられます。

3 か月ほど、ローコードで作られた管理コンソールの運用に使ってきました。画面でしか作れない設定の作成から、保存、テスト実行、結果の確認までを任せています。人が手を出したのは、保存を確定するダイアログで 1 回クリックするところだけでした。

Claude は画面を読んで複製元を探し、フォームに条件を足し、保存して、実行結果の件数まで返します。……見た目だけでなく、コンソールのエラーとネットワークリクエストも読めるからです。「表示は出ているのに API が 500 を返している」の切り分けまで届きます。

渡しているのは認証済みの状態だけです。ID とパスワードは Claude Code のコンテキストに入りません。ログイン画面や CAPTCHA では Claude が止まり、人に操作を求めます。

ここまで挙げた操作は、すべて開発環境での話です。ステージングと本番は、人がやります。これは筆者の方針です。本番で動くものの責任は、人が持つべきだと考えています。

外部オリジンの iframe を埋め込んだ画面では、中の文字を取れません。……操作はできるのに、結果が正しいかを Claude に判定させられません。

同じ作業を何度か通すと、落とし穴の場所が決まってきます。そこでスキルに書いて固定しました。……スキルには、手順のほかに人と Claude の分担表を書いています。毎回の合意が要らなくなるので、ここが一番効きました。

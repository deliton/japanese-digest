『宋史』によれば尋問の際、岳飛は衣服を脱いで、背中に刻まれた「尽忠報国」の四文字を見せたという。 何鑄は調査を進めるうちに岳飛の無実を確信し、宰相の秦檜にその結果を報告した。

ところが秦檜は「これは皇帝の意向だ」と告げ、何鑄の報告を退けようとした。 何鑄は「強敵が残っているのに、理由もなく大将を殺せば兵士たちの心を失い、国家のためにならない」と反論したという。

原文抜粋（「……」は中略）

海水には、二酸化炭素など無機物の形で存在する炭素が溶けている。これを生物が取り込み、糖やアミノ酸など炭素を骨格とする有機物に組み込む働きが「炭素固定」だ。

研究者は太陽光の届かない深海に目を向けた。ところが、そこで測った炭素固定の量は、主役と考えられてきた微生物だけでは説明できなかった。いったい誰が炭素を取り込んでいるのか。北海道大などの国際研究チームによる10年越しの研究で、意外な働き手が浮かんだ。

発端は2010年、大西洋の研究航海で行われた実験だった。……すると、有機物を加えた海水で、微生物の増殖と炭素固定がともに活発になった。光のない海では、アンモニアや硫黄化合物などを利用する「化学合成」の微生物が炭素固定の主役だと考えられていたにもかかわらずだ。

そこで研究者は、どの微生物が活発になったのかを、遺伝子の働きから探った。ところが、想定された化学合成の微生物だけでは、増えた炭素固定の量を説明できなかった。数字は増えたのに、主役がいない。別の働き手がいるのではないか。

研究チームが、無機炭素を取り込む反応に使う酵素を、どの微生物が盛んにつくっているか調べると、海のどこにでもいるが普段は少数にとどまる、ある細菌の一群が浮かび上がった。

しかも、それは他の生物がつくった有機物を「食べる側」で、炭素固定の主役とはみなされてこなかった。なぜ食べる側が、炭素固定の数字に現れたのか。

人間の心臓には長年解けない謎がある。その一つが「ミニ脳」とも呼ばれる複雑な神経系だ。心臓の機能、特に心拍数の調節に関わっていることは以前から知られていたが、具体的な仕組みや、どれほど重要な役割を果たしているのかについてはほとんど分かっていなかった。

しかし、マウスを用いた最新の研究により、「ミニ脳」が生存に欠かせないことが示唆された。心臓の「ミニ脳」は「心臓内在神経系（ICNS）」という。心臓を取り囲む脂肪組織内にあり、ヒトの場合は約4万個のニューロン（神経細胞）からなる複雑なネットワークだ。

ICNSはこれまで、主に自律神経系の中継局の役割を果たしていると考えられていた。……しかし、今回の研究により、ICNSは脳からの信号を心臓に伝える以上の働きをしていることが判明した。

原文抜粋（「……」は中略）

電源を入れて、FileVault のパスワードを入れる。進捗バーが出る。2割くらいまで進む。そこで止まる。5分待っても、10分待っても動かない。

調べたのは Claude Code です。条件を一つだけ付けました。 読み取りだけで診断すること。 設定を変えない、ファイルを消さない、プロセスを止めない、再起動しない。対処は提案までで、実行は僕が判断する。

起動が遅いなら、起動時のログを見ればいい。そう思ってのぞいてみると、 止まっていた約18分間のログが1行もありません。

dirhelper は、起動時に 一時ファイルを片付ける ためのプログラムです。カーネル内でばかり時間を使っているのは、ファイルを大量に削除しているときの典型的な姿です。つまり、 起動が止まっていたのではなく、一時ファイルを消し終わるのを待っていた 、と読めます。

Claude Code は、一時ファイルを置くための作業用ディレクトリ（scratchpad）をセッションに用意します。……僕の場合は、ここに リポジトリを丸ごと clone して yarn install する のが日常でした。

9時間半で約99万。 前回の再起動までは、6週間連続で動かしていました。単純にかけ算はできませんが、数百万ファイル以上が溜まっていてもおかしくありません（これは推定です）。

1回目は 壊れていたのではなく、削除の途中だった と考えられます。僕はそれを途中で止めて、残りを2回目の起動で消させていた。「壊れた」と思って押した長押しは、少なくとも起動を早めてはくれませんでした。

ただ、1日あたりに直すと約600GB書いています。一般的な使い方では1日に数十GBと言われるので、かなり多いほうです。

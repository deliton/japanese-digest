その中で有名なものと言えば「備中高松城の水攻め」、「播磨三木城の干し殺し」、そして今回紹介する「因幡鳥取城の渇え殺し（かつえごろし）」です。

1581年（天正9年）2月（3月か？）、無事に鳥取城に入城した経家でしたが、鳥取城の兵力は援軍を合わせて約4000人ほど。さっそく経家は鳥取城の防備に取り掛かるのですが、ここで思いもよらぬ事態が発覚します。

1581年（天正9年）6月、経家の予想を上回る速さで秀吉率いる2万の軍勢が到着。

秀吉はさっそく鳥取城を包囲すると陸路から海路に至る全ての道を封鎖し、毛利の援軍を寄せ付けません。

豊臣秀吉に若くして見出された「子飼い」の将でありながら、彼は豊臣家に背を向け、徳川家康の旗のもとに立った。

特に天正11年（1583年）の賤ヶ岳の戦いでは、一番槍・一番首の戦功を立て、賤ヶ岳七本槍の筆頭格として名を馳せる。 ここで他の七本槍が三千石の加増にとどまったのに対し、正則には五千石が与えられたことからも、その戦功の厚遇ぶりがうかがえる。

これは慶長4年（1599年）、福島正則・加藤清正・黒田長政ら武断派の有力大名が、石田三成に対して武力行使に出た事件であった。

背景には朝鮮出兵中の補給や指揮を巡る積年の不満があったとされ、とくに蔚山城の戦いに関わった加藤清正・黒田長政らの怒りが火種となったとされる。

……

これが「東軍」形成の契機となったとされ、ドラマなどでも繰り返し描かれてきた。 しかし実のところ、この劇的な場面は一次史料には確認できず、後世の創作の可能性が高いとみられている。

……

正則は行政手腕にも優れ、領国経営でも成果を挙げた実績を持つ。 性格は直情的な面が知られるものの、決して思慮に欠ける武断一辺倒の人物ではなかった。 豊臣政権内で三成の政治手腕を間近に見ていたからこそ、家康の方が今後の安定した政権運営を担えると判断していた可能性もある。

福島正則は勇猛果敢な武将として語られることが多いが、その決断の裏には、家の存続と政局を見据えた冷静な計算があったと言えるだろう。

武蔵坊弁慶は実在したのかどうか調べてみた

No Heike Monogatari Benkei é só mais um nome na tropa; a ponte de Gojō, o 'standing death' e o Kanjinchō vêm do Gikeiki. Demyth: o monge gigante que conhecemos é literatura.

草の実堂（武蔵大納言） 原文を開く ↗

原文抜粋（「……」は中略）

源義経の相棒といえば武蔵坊弁慶と決まっている。だが、当の義経についてのイメージの多くが伝説に依拠した部分も多いという。ならば、この弁慶の存在自体も虚構なのではないかという疑念が湧く。果たして、武蔵坊弁慶は実在の人物であったかのかどうか、調査を行った。

……

武蔵坊弁慶の名が「平家物語」の標準的テキストである「覚一本」に初めて登場するのは、巻九「三草勢揃」である。

一の谷の合戦に向かう義経勢の中のひとりとして名前が確認できる。

また行動をともなった一人物として描かれるのは巻九「老馬」が最初である。

この地の道案内のできる老人を探して出して連れて来るという役割を担っている。

ただしこの部分は「平家物語」の最古態を残すといわれている「延慶本」では弁慶は登場せず、義経の陣の前を通りかかった五十歳ほどの男を「枝ノ源三」（えだのげんぞう）に呼び止めさせるという記述になっている。

……

「平家物語」における弁慶は「軍勢の中のひとり」の扱いであり、役割を与えられとしても「呼び出し係（パシリ？）」程度のものに過ぎないのである。

とはいえ、「平家物語」が歴史的事実に立脚して作成された物語である以上、ここに名が記されている限りは、「武蔵坊弁慶という人物の実在が、ある程度保証される」とはいえるだろう。

……

実は現代の日本人の描く弁慶のイメージの多くは「義経記」の記述に依拠したものである。

この「義経記」の中に、義経と弁慶が五条大橋で出会う場面の原型がみられる。

「義経記」では五条大橋ではなく、五条天神となっているが、まさにこれは五条大橋での戦いの原型である。なお、決戦場所を五条大橋とする作品に、御伽草子「弁慶物語」がある。

……

また世にいう「立ち往生」についても「義経記」で見ることができる。仁王立ちになっている弁慶が既に息絶えていたことが、馬に当たって倒れてしまうことで判明する場面である。

さらに「如意の渡り」の場面。これは、「渡し守に同行の者が義経であると見破られそうになり、弁慶が扇で義経を殴り倒す」という場面である。

これこそが、のちに謡曲「安宅」、歌舞伎「勧進帳」の原型となる場面である。

Casal neolítico abraçado há 6000 anos, achado às vésperas do Dia dos Namorados. Sem feridas fatais, só oferendas de sílex — e a pergunta: amor, ritual, ou só flexão funerária?

草の実堂（北森詩乃） 原文を開く ↗

原文抜粋（「……」は中略）

およそ6000年前、新石器時代に埋葬されたと考えられる「ヴァルダロの恋人たち」は、互いに抱き合うように腕と足を絡め合う状態のまま白骨化した、男女一組の遺骨だ。

……

2007年2月、間もなくバレンタインデーを迎えるという時期に、イタリアの考古学者エレナ・マリア・メノッティが指揮するチームの手によって「ヴァルダロの恋人たち」は発掘された。

発掘された場所は、イタリア・ロンバルディア州マントヴァ郊外、現在のサン・ジョルジョ・ビガレッロ市にあるヴァルダロ地区の墓地遺跡だ。

発見された2体の遺骨は触れ合うほどの近さで顔を向かい合わせ、腕はお互いを抱き合うように、脚は折り曲げられ絡ませるような形で埋葬されていた。

詳しい調査の結果、2体の遺骨は約6000年前の男女のもので、女性は16～20歳、男性は18～22歳ほど、身長はいずれも約157cmだったと推定された。

男性の首の辺りにあった燧石(すいせき、火打石)製の矢じり、女性の大腿部あたりに1本、骨盤の下にあった2本の燧石製のナイフは、2体の遺骨に致命的な傷や骨折の痕跡が見つからなかったため、副葬品の可能性が高いとされた。

……

新石器時代や日本の縄文時代では、遺体は手足を折り曲げた状態の「屈葬」という形式で埋葬されることが多かった。

屈葬が行われた理由には諸説あるが、その1つとして胎児と同じ体勢を取らせることにより、魂の再生や死者の生まれ変わりを願ったともいわれる。

……

「ヴァルダロの恋人たち」の姿勢は、2体一組として見れば脚を絡ませ合っているように見えるが、1体ずつを見れば屈葬のようにも見える。

6000年前に死んだ「ヴァルダロの恋人たち」が、本来はどのような関係で、どのような理由で命を落とし、2人一組で埋葬されたのかはわからない。

だが少なくとも2人を埋葬した人々は、2人の死後の安寧を願っていたのではないだろうか。

……

6000年の時を経て再び人々の目に触れることになった「ヴァルダロの恋人たち」は、2011年9月、マントヴァ国立考古学博物館で初めて一般公開された。

その後、2014年4月11日からは、世界遺産に登録されたマントヴァのドゥカーレ宮殿複合施設内にあるマントヴァ国立考古学博物館で、ガラスケースに収められて常設展示されるようになった。

ヒッタイト　突然姿を消して忘れられた謎多き古代帝国

Império que empatou com Ramsés em Kadesh e sumiu por completo por volta de 1180 a.C. Egito e Assíria ficaram; os hititas viraram mistério até as tábuas de Hattusa.

ナショナル ジオグラフィック日本版 原文を開く ↗

原文抜粋（「……」は中略）

現在のトルコとその周辺に洗練された都市群を築いたヒッタイト帝国。あるとき歴史から姿を消し、数千年にわたって忘れ去られていた。しかし近年、新たな発見が相次ぎ、謎めいた古代帝国の伝説がよみがえろうとしている。

現在のトルコ中部に位置する険しい丘陵地帯に築かれた、ヒッタイト帝国の都ハットゥシャ。この都市を最盛期に見た人々は、深い畏敬の念を抱いたに違いない。日干しれんがの高い壁に囲まれ、7000人の人口を擁し、広大な神殿群や、数キロ先からも見える立派な石造りの城壁を備えていた。だが今、この丘は謎に包まれている。

宮殿や神殿の跡を示す柱や高い壁は残っておらず、枯れ草に半分覆われた石の土台が残るのみだ。都市への入り口となる門はいくつか現存し、ライオンやスフィンクス、斧（おの）を持った神の像によって守られている。だが都を囲っていた日干しれんがの壁は、数百年のうちに崩れ去った。そして洪水や雪解け水による浸食が進むと、大量の粘土板を収めた建物は斜面の下へ押し流されてしまった。権勢を誇ったヒッタイトの人々に何が起きたのか。それを知る手がかりはさらに乏しい。それでもこの失われた帝国については、以前よりもはるかに多くのことが明らかになりつつある。

……

ヒッタイト人は紀元前1180年頃、こつぜんと姿を消した。このような消え方は歴史上、ほとんど例がない。彼らは少なくとも450年間にわたり、現在のトルコとその周辺に領土をもち、その勢力範囲は黒海の沿岸近くから、メソポタミアや地中海まで及んでいた。彼らはアナトリア半島の険しい土地に洗練された都市を築き、見事な神殿や宮殿を建設した。そして楔（くさび）形文字で書き記した膨大な数の粘土板を残した。そのなかには数多くの古代語や、神聖な儀式に関する記述が含まれている。ヒッタイトの王たちは、自国から遠く離れた土地につながる交易路の恩恵を受けていた。その軍隊はメソポタミアの奥深くまで侵攻したこともある。そして「カデシュの戦い」においてエジプトのラメセス2世と戦い、世界で初めて平和条約を結んだ。

「ヒッタイト人はエジプト人と互角に戦い、バビロニア人やアッシリア人からは対等な相手として扱われていました」と、ハットゥシャの遺跡で100年近く発掘を続けるドイツ考古学研究所に在籍するアンドレアス・シャハナーは話す。それなのに「エジプト人やアッシリア人は歴史に残りましたが、ヒッタイト人は完全に消えてしまったのです」。

……

ヒッタイトの存在が認識されたのは、それから3000年後、古代エジプトの神殿でレリーフや粘土板に書かれた外交文書が発見されたときのことだ。そこから各国の研究者によるヒッタイトの都探しが始まった。ハットゥシャは当初から注目されていたが、20世紀初頭に楔形文字で書かれた大量の粘土板が発見され、ハットゥシャが都であるという説が裏づけられた。

続々と発見される遺物から、研究者はこの帝国で営まれていた生活に関する豊かな記録を集めていった。王室内のもめ事や宗教儀式、さらには犬を殺した場合の適切な処罰など、ありとあらゆる事柄に関する詳しい知識が蓄積されてきた。だが、帝国崩壊の原因については、今も謎のままだ。強大な力を誇ったヒッタイトはいったいどのようにして跡形もなく消えたのか。

原文抜粋（「……」は中略）

自作の MCP サーバーを Claude Code に入れて、快適に使っていた。ところが同じサーバーを Cursor に入れた途端、挙動がおかしくなる。

ツールを呼んでくれない／間違ったツールを使う／パラメータの渡し方がおかしい

同じ MCP サーバー、同じ設定ファイル。なのに Claude Code では動くのに Cursor で不安定。「Cursor の MCP 対応がまだ甘いのか？」と思って放置していた。

3 ヶ月追いかけて分かった原因は、もっとシンプルだった。ツールが多すぎた。

……

LLM がツールを使うとき、内部で「どのツールを、どのパラメータで呼ぶか」を推論している。この推論精度は、選択肢の数が増えるほど下がる。

Claude Code (Opus) の場合、SKILL.md でツールの使い方を詳しく教え込める。8 ツールあっても、各ツールの使い分けルールを書いておけば正しく選べる。

でも Cursor (Sonnet) や Codex ではそこまでのガイダンスを注入できない。

……

v0.6 まで 8 つのツールがあった：remember / update_memory / forget / recall / recall_file / list_entities / consolidate / read_smart

v0.7 で 3 ツールに統合したら、全クライアントで安定した。

……

自分の MCP にも使える設計原則：①ツールは 5 個以下を目指す ②似た名前のツールを作らない（recall と recall_file は LLM には曖昧）③「Claude Code で動く」≠「どこでも動く」——SKILL.md 依存は Claude Code 専用になってしまう。

MCP が Claude Code で動くのに Cursor で不安定なら、ツール数を疑う。LLM の tool selection 精度はツール数に反比例する。

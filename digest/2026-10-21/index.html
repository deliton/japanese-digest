空海が持ち帰った経典のひとつに『宿曜経（すくようきょう）』があります。……インドの占星術の初歩をまとめたもので、生まれた日の曜日によって、その人の性格や運勢を占う方法が書かれていました。こうして日・月・火・水・木・金・土という一週間の曜日が、日本に入ってきたのです。

発見された粘土板はヒッタイト語とフリル語で記されており、紀元前1375～1355年頃に在位したとされるトゥドハリヤ2世の時代にさかのぼります。……これらの文書は、21世紀に発見されたヒッタイト語文書として最も包括的なアーカイブだとのこと。

一部の粘土板文書には、都市から都市へと広がって特に子どもや乳幼児に影響したとみられる熱病についての記録があります。ある文書には、まだ母親の乳を飲んでいた幼い王女が熱病にかかり、急速に容体が悪化して亡くなったことが記されていました。

ヒッタイト王国では、病気は神の意志の表れとして考えられていたため、宗教指導者は王や官僚の子どもたちの健康状態を綿密に観察していたそうです。

他には、ヒッタイト人が鳥を使って吉凶を占っていたことを示す粘土板もありました。この粘土板には、サムハを出発してさまざまな地域を旅した鳥占い師の移動経路や滞在した都市、観察した鳥の種類などが日記のような形式で記されていました。

バイカル湖周辺で起きたペスト流行と同じ地域の墓地から、マーモットの門歯（前歯）が数百個見つかっているのだ。その長く湾曲した門歯は装飾品として珍重され、副葬品として埋葬されたとみられる。

実際、シベリアマーモットはペスト菌に感染しても50％から80％が生き延びる。……ロシアの研究チームは、ペスト菌がげっ歯類の巣の敷き材で400日以上生存することを確認している。

ペスト菌は粘液の栓でノミの腸を塞ぐことが知られている。するとノミは飢餓状態になり、温かいものなら何でも、手当たり次第に何度も咬むようになる。こうして動物の病気がヒトに広がってゆく。

やがて干ばつが起き、げっ歯類が激減すると、ノミの数が宿主に対して過剰になる。「ノミは過密状態になると落ち着きがなくなります」。

ところが、ソ連の計画立案者たちは、土地は人間の思いどおりにできると考えていた。……マーモットも、そしてペストもそうした試みを生き延びた。1990年までにはペスト撲滅計画は終了した。

原文抜粋（「……」は中略）

AI コーディングエージェントを使って開発していると、実装と一緒にテストも増えていき、気づいたときには膨大な量になっていることがあります。私が担当しているプロダクトも例外ではなく、PR CI の待ち時間は長いときで 18 分を超え、日々の開発で地味なストレスになっていました。

まず、Claude Code に実行時間の内訳を計測させました。CI と同じ 2 CPU の環境で Vitest を計測すると、400 秒のうちテスト本体は 57 秒で、全体の 14% 程度でした。残りの大部分は、テストファイルごとの環境の起動など、テスト実行前のオーバーヘッドだと判明しました。

対策 : Vitest の projects （1 つの設定の中で、テストの種類ごとに異なる設定を定義できる機能）でユニットテストを分割しました。.ts は node 環境、.tsx は jsdom 環境で実行します。

対策 : マイグレーション適用後の DB を pg_dump （PostgreSQL のバックアップ用コマンド）でダンプし、Actions キャッシュに保存しました。……PR ブランチで保存したキャッシュは、その PR の再実行からしか参照できません。他の PR と共有するには main ブランチで保存する必要があるため、キャッシュを作成するワークフローを別途用意しています。

分割すると問題になるのがテストカバレッジです。分割したジョブ単体では、カバレッジがしきい値を下回ります。そこで、各ジョブの結果を blob レポート……として保存し、最後のジョブで合算してからしきい値を判定するようにしました。

キャッシュを増やした結果、想定していなかった問題が起きました。Actions キャッシュの合計サイズが 11.9 GB に達し、リポジトリの上限（デフォルトで 10 GB）を超えていました。

いちばん効いたのは、施策を考える前に実行時間の内訳を計測したことです。テスト本体は全体の 14% にすぎず、ボトルネックはテスト実行前のオーバーヘッドにありました。
